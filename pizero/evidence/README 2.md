# pizero/evidence

Captured board state, same convention as `pi/evidence/`. Nothing here is generated by a build —
it is what a running unit reported, and it is the only record once the board is powered down.

    ssh zeno@192.168.51.2 'sudo pizero_verify.sh' | tee pizero/evidence/verify_$(date +%F).txt

Commit the report. The four divergences in `pizero/README.md` are claims about this hardware, and a
dated report is what turns them into measurements.
