# Tier-0 JVM unit tests, run by tools/test.sh (kotlinc + JUnit 4, no Gradle).
#
# FORMAT (owned by plan v5.8 unit V6 / VC):
#   * one fully-qualified test class per line, e.g. zeno.gmccpa.av.FgsGateTest;
#   * its source MUST be netprobe_app/app/src/test/java/<package path>/<Class>.kt — the path is
#     derived from the name, so a class whose file is elsewhere is a gate failure, not a skip;
#   * `#` starts a comment (whole line or trailing); blank lines are ignored;
#   * a class may appear once only (a duplicate fails the gate).
#
# The step compiles the WHOLE main source root plus every listed test source against android.jar +
# android.car.jar (compile classpath only) and runs the classes with no Android on the runtime
# classpath, so a test that reaches a real Android call fails loudly. The ONLY Android classes at
# runtime are the stubs in tools/jvm_stubs/ (a recording android.util.Log and a throwing
# android.os.SystemClock, from the v5.7 U3 harness). Adding a stub there is a reviewed change to the
# gate, not a way to make a failing test pass.
#
# APPEND-ONLY, one block per unit: add a `# --- <unit> (<agent>) ---` header and your class lines at
# the END of the file. Do not reorder, edit or delete another unit's block; removing a test is a
# change to that unit's plan, not to this list.
